# Carrier OS — Armed vs Unarmed

A public, branded presentation of the CarrierOS local reasoning evaluation from September 12, 2026.

The report compares the same model across three conditions: operating alone, operating inside CarrierOS with tools, and operating with the resident Carrier framework. It presents all 24 graded questions and the headline fabrication result: **4 → 2 → 0**.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The original evaluation materials used by the published report are included under `evaluation-data/`. Low-level proxy logs are intentionally excluded because they contain runtime and infrastructure traces that are not needed to verify the published results.
